# Curso React: Rotas com React Router

Projeto de estudo em React com navegação entre páginas usando React Router v6.

## O que o projeto faz

- Página **Home** (`/`) com link para a página Sobre
- Página **Sobre** (`/sobre`)
- Navegação entre páginas sem recarregar o site, usando `Link`

## Tecnologias

- React
- React Router DOM v6
- JavaScript (ES6+)

## Estrutura

```
src/
├── pages/
│   ├── Home/
│   └── Sobre/
├── Routes.js
└── index.js
```

## Como rodar

1. Clone o repositório:
   ```
   git clone https://github.com/guttembergbilacdev/curso.git
   ```
2. Entre na pasta e instale as dependências:
   ```
   cd curso
   npm install
   ```
3. Inicie o projeto:
   ```
   npm start
   ```
4. Abra `http://localhost:3000` no navegador.

## O que aprendi

- Configurar rotas com `BrowserRouter`, `Routes` e `Route`
- Usar `element={<Componente />}` na v6
- Navegar entre páginas com `Link`
- Versionar o projeto com Git e GitHub
